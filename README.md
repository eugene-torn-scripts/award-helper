# Award Helper

Torn userscript that helps you collect awards (merits) faster with the energy and nerve you already spend.

## Attack page
- **Finish with** – highlights the weapon slot that counts for the closest open finishing-hit award (Slasher, Unarmed, Leonidas kick, Stumped, Machinist, …; War Machine after 100).
- **Warns** when none of your equipped weapons counts for an open finishing-hit award.
- **Armor** – warns while you wear armor and Bare (250 unarmored wins) is open.
- **Special ammo** – tells you which owned special ammo to load (Surplus / Bandolier / Quartermaster, Maimed / Penetrated / Scorched / Marked) and reminds about Dragon's Breath.
- **Abroad** – shows when a win counts for International.
- **Bounty** – highlights targets with a bounty (Bone Collector / Bounty Hunter / The Fett / Dead Or Alive).

## Other pages
- Small reminder when the daily energy or nerve refill is not used and Energize / You've Got Some Nerve is open (hide until next TCT day).

## Panel
Footer menu → Award Helper: API key, reminder toggles, progress of all tracked awards.

## API key
A Minimal access key is enough. A Limited key also shows your current kill streak. The key stays in your browser (Torn PDA key is used automatically).
